# UNO Pro Advanced

Неофициальный расширенный редактор, библиотека и рабочая среда секвенсора для **IK Multimedia UNO Synth Pro**.

Текущая версия разработки: **v0.9.0-beta**  
Точка перехода со старой нумерации: **v1.64 FIX2**

> Проект входит в стадию beta-тестирования. Старые архивы v1.x сохраняют свои исторические номера; новые версии используют pre-1.0 beta-нумерацию. Подробности: `Docs/VERSIONING.md`.

## Что уже есть

- Редактирование параметров синтезатора в реальном времени по MIDI.
- Локальная библиотека пресетов и навигация по аппаратным пресетам.
- ARP + 64-шаговый секвенсор / piano roll.
- Режимы SONG и LIVE.
- Экранная клавиатура с Pitch Bend, MOD и сменой октав.
- Чтение аппаратной секвенции в нормальном режиме через подтверждённый протокол `0x29`.
- MIDI Clock Master и транспорт по MIDI/USB.
- Подробная документация по протоколу и аппаратным тестам в `Docs/`.

## Текущее состояние протокола

На реальном устройстве подтверждены выбор/имя пресета, чтение текущего состояния, чтение страниц пресета через `0x29`, а также работа MIDI Clock и PLAY/STOP при USB-синхронизации.

Текущие ограничения:

- Аппаратная команда **SEQ ON/OFF** пока не декодирована. Clock и PLAY/STOP работают, но включение/выключение самого аппаратного секвенсора требует отдельной подтверждённой команды.
- Постоянная запись STORE остаётся заблокированной. Неподтверждённые потенциально разрушительные SysEx-команды не включаются.
- Во время beta-тестирования продолжается доводка UI и рабочего процесса секвенсора.

## Требования

- Windows для прямой работы MIDI через WinMM.
- Python 3.10+
- Pillow >= 10.0

## Запуск

```bash
pip install -r Docs/requirements.txt
python main.py
```

В Windows также можно использовать `install_dependencies.bat` и `run_editor.bat`.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `main.py` | Точка входа |
| `app.py` | Основной Tkinter-интерфейс и логика приложения |
| `midi_interface.py` | Низкоуровневый WinMM MIDI / SysEx слой |
| `midi_engine.py` | MIDI transport, clock, CC и ноты |
| `protocol_map.py` | Подтверждённые карты протокола и генераторы запросов |

| `storage.py` | Сохранение пресетов, песен и настроек |
| `unosyp_state_decoder.py` | Декодирование состояния `.unosyp` |
| `unosyp_seq_decoder.py` | Декодирование секвенции `.unosyp` |
| `Docs/` | Состояние проекта, протокол, тесты и история сборок |

## Нумерация версий

Старая внутренняя нумерация заканчивается на **v1.64 FIX2**. Далее:

- `v0.9.x-beta` — небольшие исправления и проверочные сборки;
- `v0.10.0-beta`, `v0.11.0-beta` и далее — крупные функциональные этапы;
- `v1.0.0` — первый подтверждённый стабильный релиз.

Исторические архивы и документы не переименовываются.

## Правило безопасности

В протокол добавляются только подтверждённые MIDI/SysEx-мэппинги. Неподтверждённые команды не придумываются и не используются для постоянной записи. STORE остаётся заблокированным до достаточного декодирования и аппаратной проверки пути записи.
