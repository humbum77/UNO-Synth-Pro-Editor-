UNO Synth Pro Editor v1.15 — ENV / FILTER / MOD VISUAL

Пакет исправлений по замечаниям после v1.14:
- ENV: убрано искусственное скругление геометрии. A=0, D=0, S=127, R=0 отображается почти прямоугольником.
- ENV: Release теперь реально изменяет последний участок графика.
- Добавлена плавная анимация перехода экранных графиков между значениями (без изменения точных MIDI-значений).
- Добавлен голубой индикатор прохождения огибающей по ADSR при Note On/Off.
- FILTER: две кривые одновременно, разными цветами.
- FILTER 1: визуальная модель 2-pole OTA LP/HP (~12 dB/oct), Bypass = прямая.
- FILTER 2: визуально различаются 2-pole и более крутой 4-pole SSI LP; Bypass = прямая.
- FILTER: Filter ENV визуально двигает cutoff при Note On/Off согласно ENV Amount.
- MOD MATRIX: для видимых destination добавлена тонкая голубая modulation overlay на соответствующем контроле.
- INIT defaults фильтров: Cutoff=127, Resonance=0, Env Amount=0, Key Tracking=0.
- Spacing default=0; UI диапазон Spacing -63..+64.
- Env Amount: -64..+64, bipolar, default 0.
- Key Tracking: -200..+200%, bipolar, default 0.
- Matrix Amount default=0 сохранён.

ВАЖНО:
Графическая анимация огибающей/фильтра — визуальная модель, синхронизированная с MIDI Note On/Off и параметрами редактора. Это не измерение аналогового сигнала внутри UNO.
Точные неподтверждённые значения переключателей режимов фильтров и CUTOFF/CUT+RES не угадывались.
