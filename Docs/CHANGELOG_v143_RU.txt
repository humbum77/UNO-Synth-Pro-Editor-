UNO Synth Pro Editor v1.43 — cumulative build

Исправления по аппаратному тесту UNO:
- DELAY: порядок типов строго MONO / STEREO / DOUBLER / PING PONG / LCR.
- DELAY: исправлено декодирование аппаратного энкодера по enum-шагам 0/25/50/75/100.
- DELAY GUI: MONO/STEREO/DOUBLER в первом ряду; PING PONG/LCR во втором рядом с SYNC.
- DELAY: AMOUNT поднят на один ряд, лишний резерв удалён.
- REVERB: исправлен выбор SPRING аппаратным энкодером; enum 0/25/50/75.
- REVERB: AMOUNT поднят на один ряд, лишний резерв удалён.
- MODULATION: верхний тип жёстко ограничен CHORUS/PHASER/FLANGER; лишние аппаратные значения больше не могут ломать отрисовку DELAY/REVERB/MOD MATRIX.
- MODULATION: аппаратные enum-шаги 0/25/50.

Системные исправления:
- UNO -> GUI: входящие CC теперь складываются в потокобезопасную очередь и обрабатываются каждые 10 мс.
- Внутри каждого 10-мс окна промежуточные CC одного параметра отбрасываются, применяется последнее значение. Это устраняет накопление очереди и заметную задержку фейдеров/энкодеров.
- MIDI Clock, Note и SysEx не коалесцируются.
- DELAY TIME R обновляет собственный правый фейдер.
- Аппаратное изменение фейдера показывает цифровое значение рядом с соответствующим контролом.
- При перетаскивании мышью цифровое значение появляется над текущей позицией курсора.
- Двойной клик по фейдеру открывает постоянное цифровое поле: оно переживает redraw и закрывается только Enter/Esc.
- ENV: редактирование всей линии ADSR использует реальную дистанцию до сегмента (~8 px), а не весь прямоугольник вокруг сегмента.
- Resize: окно сохраняет пропорции текущего design canvas, исключая пустые letterbox/pillarbox зоны.

Сохранены накопительные изменения v1.40-v1.42: LIVE paths/UI, sequencer indicator, Matrix Amount MIDI, FX MIDI mapping, FX dynamic GUI, numeric editing, ENV line editing и прочие ранее внесённые изменения.
