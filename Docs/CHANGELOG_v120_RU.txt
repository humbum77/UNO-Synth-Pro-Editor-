UNO Synth Pro Editor v1.20 — Compact / LFO / ENV controls

Проверенный пакет изменений:
1. Стартовый размер окна 1024x640; вся исходная геометрия масштабируется пропорционально.
2. INIT OSC: OSC1 Saw + Level 127; OSC2 Triangle + Level 0; OSC3 Triangle + Level 0.
3. FILTER: центральная группа, вертикальные контролы, SPACING и CUTOFF/CUT+RES подняты вверх; кнопки больше не лежат на нижней границе панели.
4. LFO1/LFO2: возвращены LIN / EXP / LOG.
5. LFO WAVE: отдельный WAVE-фейдер убран. ЛКМ на экране + движение вверх/вниз меняет WAVE 0..127 без сглаживания управления. Двойной клик открывает числовой ввод.
6. FILTER ENV и AMP ENV: добавлены четыре интерактивные ADSR-точки. Attack/Decay/Release редактируются по времени, Sustain — по уровню; фейдеры синхронизируются.
7. Safe Start сохранён: MIDI не подключается при запуске; только SETTINGS > APPLY.
8. Standalone MIDI Monitor в пакет Editor не включён.

Примечание: LIN/EXP/LOG возвращены как UI-состояние. Аппаратную MIDI-команду для этого переключателя эта сборка не выдумывает и не отправляет до подтверждения протокола.
