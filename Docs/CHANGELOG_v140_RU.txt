UNO Synth Pro Editor v1.40 — изменения

SYNTH / FX
- В MODULATION, DELAY и REVERB всё содержимое, кроме заголовков, сдвинуто вниз на 40 px (область заголовка 30 px + 10 px).
- DRIVE не изменён.

ARP + SEQUENCER
- Индикатор текущего шага заменён с оранжевого на светло-серый полупрозрачный визуальный слой (Tk stipple) одновременно в Piano Roll, Step Parameter и LINE.
- Добавлено автоследование 16-шагового окна за транспортом: 1–16 / 17–32 / 33–48 / 49–64.
- TARGET уменьшен по ширине; его правый край точно совпадает с правым краем контейнера automation.
- Текстовые quick guide выровнены по центру контейнеров.
- LMB в quick guide заменён пиктограммой мыши без боковых стрелок.

ПУТИ ПО УМОЛЧАНИЮ
- Пресеты: ~/Documents/IK Multimedia/UNO Synth Pro Editor
- SONG / LIVE: ~/Documents/IK Multimedia/UNO Synth Pro Editor/SONGS
- Каталоги создаются автоматически при необходимости.

LIVE
- Удалены отдельные кнопки LOAD SELECTED и STOP.
- PLAY — одна большая квадратная кнопка; повторное нажатие после запуска выполняет STOP.
- Добавлена настройка DELAYED START 5–60 секунд.
- Во время обратного отсчёта повторное нажатие большой кнопки отменяет запуск.

Не изменялось
- Интерфейс транспорта SONG оставлен как в базовой v1.39.
- Существующая MIDI transport / clock логика секвенсора не заменялась внутренним программным clock.
