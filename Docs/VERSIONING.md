# Versioning

UNO Pro Advanced has moved to pre-1.0 semantic-style beta versioning.

## Transition

- Legacy development baseline: `v1.64 FIX2`
- New beta baseline: `v0.9.0-beta`

Historical archives and documents keep their original version numbers. They are not renamed.

## Rules going forward

- Small fixes and validation builds increment the patch component: `0.9.1-beta`, `0.9.2-beta`, ...
- Significant functional milestones increment the minor component: `0.10.0-beta`, `0.11.0-beta`, ...
- The first validated stable release will be `v1.0.0`.
- `FIX`, `FIX2`, `FIX3` suffixes are no longer used for new builds.

The repository starts the new numbering at `v0.9.0-beta`, using the code state reached at legacy `v1.64 FIX2` as the transition baseline.
