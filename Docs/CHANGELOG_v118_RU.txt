UNO Synth Pro Editor v1.18

ИЗМЕНЕНО
- Полностью удалена визуальная интерполяция/задержка параметров.
- Фейдеры и тонкие линии следуют за мышью 1:1.
- MIDI CC отправляется непосредственно из set_value без анимационного буфера.
- Входящий MIDI сразу меняет значение контрола.
- OSC/LFO/ENV/FILTER графика использует текущее значение параметра сразу.
- Таймер 60 FPS оставлен только для реальной временной визуализации ENV/LFO/модуляции FILTER.
- Anti-aliasing графиков сохранён: он не является временным сглаживанием.
- Standalone MIDI Monitor удалён из Editor-пакета и далее живёт отдельно.

НЕ ИЗМЕНЕНО
- Подтверждённые MIDI mappings FILTER из v1.17.
- Direct numeric entry по двойному клику.
- Временная модель ENV и визуализация результата модуляции FILTER.
