UNO Synth Pro Editor v1.13 — пакет исправлений пользователя

1. Все дискретные селекторы проекта переведены на единый раскрывающийся список внутри интерфейса Canvas. Клик больше не перебирает значения по кругу. Длинные списки показывают до 10 строк и прокручиваются колесом.
2. SETTINGS использует тот же встроенный drop-down. Выбор MIDI Controller не открывает порт до APPLY; MIDI connect остаётся асинхронным.
3. Цифровые значения возвращены на линейные/вертикальные контролы.
4. LFO WAVE — числовой параметр 0–127. Графическая форма не подменяет числовое значение.
5. OSC WAVE — 0–127.
6. В каждом OSC LEVEL расположен второй строкой непосредственно под WAVE.
7. OSC TUNE — логический биполярный диапазон -24…0…+24, шаг 1 semitone; 0 в центре. В MIDI CC значение нормализуется в 0…127. Входящий CC15/16/17 преобразуется обратно в -24…+24.

Не менялось: неподтверждённые SysEx STORE/SEND/DEPLOY остаются заблокированы.
