UNO Synth Pro Editor v1.12 — проверка текущего пакета SETTINGS

Исправлено:
1. SETTINGS используют выпадающие списки, а не перебор стрелками.

3. MIDI CONTROLLER присутствует.

Важно по MIDI mapping:
Текущая версия НЕ имеет полного связывания каждого элемента UI со всей MIDI Implementation Chart. Реальный MIDI output включен только для параметров, которые есть в protocol_map.CC, плюс подтвержденные ARP SysEx, Program/Bank, клавиатура, Mod Wheel/Pitch Bend и READ 0x37. Остальные UI-параметры пока могут быть только визуальными/локальными до точного сопоставления.
