UNO Synth Pro Editor v1.22 — финальная компоновка SYNTH перед SEQUENCER

- Базовое окно: 1100x690.
- MOD MATRIX: 4 компактные строки, маленькие элементы, увеличен только межстрочный зазор; строки 5–16 через скролл.
- Освободившаяся высота отдана OSC/FILTER/LFO/ENV; графические экраны слегка увеличены по высоте.
- FILTER: заголовок и подписи больше не пересекаются; центральная группа размещена внутри панели; график опущен примерно на 2 мм и F1/F2 слегка разведены по вертикали.
- FILTER ENV / AMP ENV: более высокие экраны; AMP ENV не пересекает заголовок; ADSR-точки маленькие, сплошные оранжевые, без белого ободка.
- FX: панель остаётся узкой, но внутренние фейдеры/AMOUNT пересчитаны под её ширину и не выходят за край.
- OSC: WAVE screen-drag сохранён; INIT OSC1 Saw/127, OSC2 Triangle/0, OSC3 Triangle/0; NOISE отдельно снизу по центру.
- LFO: screen-drag, SYNC/RETRIG перед экраном, LIN/EXP/LOG сохранены.
- SAFE START и отдельный Standalone Monitor не изменялись.
