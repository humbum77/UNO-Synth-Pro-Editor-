UNO Synth Pro Editor v1.29 — FILTER + SEQ UI

Сборка строго по согласованному пакету после v1.28.

FILTER
- FILTER перестроен по утверждённому эскизу без растягивания элементов; свободные области оставлены свободными.
- Заголовок FILTER центрирован.
- Слева и справа: CUT / RES / ENV / KEY. TRACK переименован визуально в KEY; MIDI-ключи F1_TRACK/F2_TRACK и подтверждённые CC не изменены.
- 4 вертикальных фейдера с каждой стороны имеют одинаковый шаг.
- KEY слева и CUT справа находятся на одинаковом расстоянии от экрана FILTER.
- Нижний левый dropdown выровнен левым краем по линии CUT; правый dropdown — правым краем по линии KEY.
- Dropdown режимов и кнопки CUTOFF / CUT+RES имеют одинаковую высоту.
- CUTOFF / CUT+RES вместе строго занимают ширину экрана FILTER: внешний левый край CUTOFF = левый край экрана, внешний правый край CUT+RES = правый край экрана.
- SPACING расположен непосредственно под экраном и имеет его ширину.

ARP + SEQUENCER
- PLAY -> PLAY ▶; REC -> REC ●. Логика транспорта/записи не изменялась.
- Под PATTERN добавлен компактный QUICK GUIDE: ON STEP = note plays; EMPTY STEP = MUTE; click 1–16 toggles step.
- Под SEQUENCE SETTINGS добавлен компактный QUICK GUIDE по LMB, Shift+LMB Pencil, вертикальному и горизонтальному скроллу и вводу STEPS.
- STEPS 1..64 переделан из медленных +/- в тонкий линейный control общей стилистики.
- STEPS можно быстро менять drag мышью по всему диапазону 1..64.
- Double-click STEPS открывает ввод значения с клавиатуры; Enter применяет, диапазон clamp 1..64.
- Значение STEPS показывается popup только во время редактирования.

СОХРАНЕНО ИЗ v1.28
- PLAY toggle / REC, запись нот и выбранной LINE automation.
- MIDI autoconnect к сохранённым портам.
- LINE 1–4 и только 10 TARGET: CUTOFF 1/2, RESONANCE 1/2, WAVE 1/2/3, SPACING, FM 1/2.
- Ноты Piano Roll визуально на полную ширину шага.
- Общий horizontal scrollbar под Piano Roll.
- Глобальная клавиатура, SONG, LIBRARY, SETTINGS и остальные секции не перерабатывались.
