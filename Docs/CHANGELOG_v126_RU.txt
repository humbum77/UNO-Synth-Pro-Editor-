UNO Synth Pro Editor v1.26 — Sequencer Scroll + Polymetric Steps

Изменения только в ARP + SEQUENCER и ARP INIT:
- STEPS удалён из ARPEGGIATOR и перенесён в SEQUENCE SETTINGS.
- STEPS = реальная длина секвенции 1..64, изменение кнопками -/+ по одному шагу.
- Ширина шага постоянная: одновременно видно 16 шагов, при прокрутке сетка не сжимается.
- Piano Roll, Step Parameter и MOD Automation используют общий горизонтальный scroll offset.
- Общий горизонтальный индикатор прокрутки внизу центральной секции.
- Piano Roll: диапазон C0..C7; стартовая нижняя видимая нота C2.
- Добавлен видимый вертикальный scrollbar Piano Roll и прокрутка колесом.
- Каждый 4-й шаг отделён более яркой вертикальной линией.
- Шаги после текущего STEPS остаются видимыми, но затемнены.
- Строки белых клавиш Piano Roll светлее строк чёрных клавиш.
- Ноты имеют 12-цветную хроматическую палитру, повторяющуюся по октавам; A = красный.
- ARP PATTERN INIT: все 16 шагов ON.
- MOD Pencil сохранён: Shift+ЛКМ, 4 внутренних сегмента на шаг.
- OVERDUB MONO ограничивает ручной ввод одной нотой на шаг, POLY — тремя.

SYNTH / SONG / LIBRARY / SETTINGS не перерабатывались.
