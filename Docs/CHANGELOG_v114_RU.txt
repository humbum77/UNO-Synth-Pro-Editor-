UNO Synth Pro Editor v1.14 — DISPLAY + FILTER FIXES

Пакет исправлений по замечаниям после v1.13:
1. Убраны постоянные цифровые значения со всех line/fader-контролов.
2. Значение показывается только временным popup во время drag; после отпускания исчезает. Колесо мыши показывает popup кратковременно.
3. На графических экранах цифровые значения не рисуются.
4. LFO: добавлена визуализация формы волны; WAVE остаётся внутренним диапазоном 0–127.
5. OSC WAVE: увеличена плотность точек и включено сглаживание линии.
6. ENV/LFO/FILTER: включено сглаживание линий; Square/S&H сохраняют резкие переходы.
7. FILTER: одновременно рисуются две кривые: Filter 1 (orange) и Filter 2 (blue).
8. Filter 1 HP рисуется с обратным направлением относительно LP; BYPASS — горизонтальная линия.
9. Переключение F1/F2 mode немедленно перерисовывает экран.
10. FILTER SPACING по умолчанию = 0 (центр биполярной линии).
11. MOD MATRIX: AMOUNT всех 16 маршрутов по умолчанию = 0.
12. OSC2/OSC3: TUNE/FINE/FM подняты на 10 px; NOISE поднят и полностью помещается в секции.
13. WAVE → LEVEL в OSC сохранено: LEVEL второй строкой под WAVE.
14. TUNE сохранён биполярным −24..+24, центр 0.

ВАЖНО ПО MIDI:
- MIDI-движок и подтверждённые CC не переделывались.
- F1_MODE/F2_MODE по-прежнему отправляются через известные CC30/CC37, но точные значения режимов требуют отдельного подтверждения Monitor.
- Кнопки CUTOFF / CUT+RES пока не отправляют неизвестные команды: их протокол нужно снять Monitor.
