UNO Synth Pro Editor v1.19 SAFE START

ИСПРАВЛЕНО:
1. Полностью отключено автоматическое MIDI-подключение при запуске.
2. При запуске больше не выполняется даже перечисление WinMM MIDI-портов.
3. MIDI-порты сканируются только после явного открытия SETTINGS; сканирование идёт в отдельном потоке.
4. Фактическое MIDI-подключение выполняется только после нажатия APPLY.
5. Удалён постоянный 60 FPS animation timer. Таймер создаётся только когда реально меняется ENV или есть активная LFO-модуляция; частота ~30 FPS.
6. При закрытии активный animation job отменяется.
7. OSC1/OSC2/OSC3 используют один и тот же непрерывный морф WAVE:
   Triangle -> Saw -> плавный Saw->Square 50% -> PWM до 98%.
   Убраны синус в начале и скачок Saw->Square.
8. Сохранены изменения v1.18: фейдеры/линии меняются без интерполяционной задержки.
9. Сохранены подтверждённые Monitor-тестами FILTER MIDI mappings из v1.17/v1.18.

БЕЗОПАСНЫЙ СТАРТ:
- Статус при запуске: OFFLINE.
- Никакие MIDI IN/OUT не открываются автоматически.
- Для подключения: SETTINGS -> выбрать порты -> APPLY.
